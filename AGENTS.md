# ODBS (Öğrenci–Danışman Otomasyonu)

Önce `docs/DEVIR-TESLIM.md` dosyasını oku: proje bağlamı, hocaya söylenen durum ile gerçek durum farkı (hocaya giden belgelerde plan dili),
iş kuralları, çalıştırma, test ve planlanan işler orada. Kararların gerekçeleri `docs/DECISIONS.md`'de.

Kısa kurallar: Türkçe yaz; belirsizlikte makul varsayımla ilerle ve kararı `docs/DECISIONS.md`'ye yaz; "araştır / planla" denince kod yazma;
yeni endpoint için yetki taramasını güncelle; bitti demeden `cd backend && dotnet test` ve `cd frontend && npm run lint && npm run build` çalıştır.
